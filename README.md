# adfree3kh0 home page

This repo serves the home page for `adfree3kh0.github.io`.
GitHub disabled the old root repo and will not restore it.
This page is the replacement. It lives at https://adfree3kh0.github.io/home/.

The page links to the ad-free game sites that still work.
The Plausible tag keeps the site id `adfree3kh0.github.io`.
Plausible keeps the traffic history in one site.

## Files

- `index.html` — the page. One file. No build step.
- `.nojekyll` — tells GitHub Pages to skip Jekyll.

## Preview locally

1. Run `python3 -m http.server 8510`.
2. Open http://localhost:8510/.

## Deploy

1. Create the repo `adfree3kh0/home`.
2. Push branch `main`.
3. Enable GitHub Pages for branch `main`, folder `/`.
4. Open https://adfree3kh0.github.io/home/.
